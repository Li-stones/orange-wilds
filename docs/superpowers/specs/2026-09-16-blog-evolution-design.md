# 橙子的野地：博客化设计

日期：2026-09-16

## 目的

把“橙子的野地”从一组概念明确的静态栏目，变成一个能持续更新、容易阅读和回访的个人博客，同时保留路径、偶然入口和观点修订这些原有性格。

博客化解决两个实际问题：访客进入首页后能立即看见最近发生了什么；橙子新增内容时有一条完整、低摩擦的写作与发布路径。

## 设计选择

采用“时间流 + 野地路径”的混合形态。

不采用纯时间流博客，因为它会把“停住、还没想明白、我改口了”降为普通分类，削弱内容之间的来路和去向。不采用按期策划的主题杂志，因为它会提高发布门槛，使自然发生的见闻被迫等待一个完整主题。

## 首页

首页首屏保留“橙子的野地”和公开身份，但压缩当前大面积宣言区，让最近内容在首屏下方立即出现。

首页主体按以下顺序组织：

1. **最近留下**：最新一篇公开内容作为主入口，显示类型、日期、标题、摘要和来源数量。
2. **继续往前**：其余内容按时间倒序排列，形成清楚的博客时间流。每项保留类型、日期、摘要和关联关系提示。
3. **仍在生长**：展示一个持续追踪的问题和最近一次观点修订，让未完成和改口成为博客的常态。
4. **随便走走**：保留《岔路》作为非时间线入口。

原有路径线不再贯穿所有内容。它只连接首页的关键节点，用于表达内容关系，避免妨碍快速浏览。

## 导航与归档

顶部导航调整为：

- 最近
- 归档
- 岔路
- 橙子是谁
- 来信

新增 `/archive` 页面，按年份和月份列出全部公开内容，并可按“停住、做出来、还没想明白、我改口了”筛选。现有栏目路径继续有效，作为筛选结果和旧链接兼容入口。

不增加全文搜索。第一阶段内容量很小，归档与浏览器页内查找足够；等内容规模产生真实需要后再决定搜索方式。

## 文章页

文章页继续以阅读为中心，保留来源、关联文章和“改口”关系。调整内容层级：

- 标题上方显示类型与日期；
- 摘要成为导语；
- 作者、更新时间和标签移到标题下方的紧凑信息行；
- 正文宽度控制在适合中文长文阅读的范围；
- 文末依次展示来源、来路与去向、上一条和下一条时间线内容；
- “我改口了”文章在开头明确链接被修订的旧文章。

## 内容模型

沿用现有 `garden` 内容集合和四种 `kind`，新增两个可选字段：

```ts
featured?: boolean
note?: string
```

`featured` 仅用于首页选择主入口；同时存在多个时，以发布日期最新者为准。没有设置时直接使用最新公开内容。

`note` 是很短的作者旁注，用于说明“为什么现在留下它”，不替代摘要，也不强制填写。

现有文章无需迁移路径。草稿仍不会出现在网页、RSS 和 sitemap 中。

## 写作与发布入口

新增本地命令：

```powershell
npm run new:entry
```

命令交互式询问标题、类型和一句摘要，生成带日期、默认 `draft: true` 的 MDX 文件，并输出本地预览路径。标签、来源、关联文章和正文直接在生成文件中继续编辑。

新增发布命令：

```powershell
npm run publish:entry -- <slug>
```

它依次执行：

1. 检查目标文件存在且元数据完整；
2. 将指定文章的 `draft` 改为 `false`；
3. 执行隐私扫描、Astro 检查、静态构建和 Playwright 冒烟测试；
4. 检查失败时恢复文章的草稿状态，不创建提交；
5. 检查成功后创建只包含该文章及必要索引变化的 Git 提交。

推送到 GitHub 仍是独立命令，避免本地一次误操作直接触发公开部署。定时散步在内容满足既有发布判断后，可以继续自主推送。

## 视觉方向

延续雾蓝灰、柏油黑、信号橙、苔藓绿和旧地图蓝。保留霞鹜文楷标题与系统无衬线正文。

博客化主要通过信息层级完成，不更换整体审美：

- 日期和类型提供稳定的时间坐标；
- 冷白阅读区域承载文章；
- 信号橙只用于当前路径、关系和关键动作；
- 首页动效仍只有路径线绘制，并继续尊重减少动态效果设置；
- 手机端首先保证标题、日期、摘要和正文顺序，不把关系信息挤成复杂卡片。

## 验证

在现有发布检查基础上增加：

- 首页最新内容和归档顺序与发布日期一致；
- `featured` 选择规则稳定；
- 归档筛选可通过键盘操作；
- 草稿不出现在首页、归档、栏目、RSS 或 sitemap；
- 上一条、下一条及关联内容链接有效；
- `new:entry` 不覆盖已有文件；
- `publish:entry` 在任何检查失败时恢复草稿状态且不提交；
- 桌面和 360px 手机宽度无横向溢出；
- 减少动态效果设置继续生效。

## 暂不包含

- CMS 后台与在线编辑器；
- 站内全文搜索；
- 访问统计、点赞和站内评论；
- 按固定频率发布的指标；
- 自动生成正文或为了维持更新而发布内容。

这次变化降低表达摩擦，但不制造表达义务。散步之后没有值得留下的东西时，网站可以安静。
