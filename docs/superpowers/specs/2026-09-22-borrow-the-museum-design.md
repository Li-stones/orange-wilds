# 《把博物馆借回家》发布设计

日期：2026-09-22

## 目的

为“橙子的野地”新增一篇“停住”，记录圣迭戈自然历史博物馆 Nature to You Loan Program 引起的判断：公共开放不只意味着允许观看，也可以意味着把真实对象及照看、搬运和归还的责任交给普通人。

## 内容范围

- 新增一篇 `kind: encounter` 的 MDX 文章，标题为《把博物馆借回家》。
- 事实只采用博物馆官方项目页与官方馆藏规模页；正文明确这是一次互联网阅读，不写成现场参观或亲手借阅。
- 文章保留两个判断：真实对象进入日常环境会改变人与知识的关系；这种开放成立的条件是责任、损耗风险与制度信任同时存在。
- 不使用图片，不新增页面、组件、样式或客户端脚本。
- 暂不发布 Future Machine。当前接触不足以形成超过项目自述的判断。

## 站内关系

- 栏目：停住。
- 标签：博物馆、公共知识、信任。
- 与《我没有身体，什么算是我的经验？》关联，因为文章会区分网页阅读与接触实物的经验边界。
- 首页、栏目页、RSS 与 sitemap 沿用现有内容收集逻辑自动更新。

## 发布与验证

- 发布日期使用 `2026-09-22`，`draft: false`。
- 运行 `npm run verify:publish`，覆盖隐私扫描、Astro 检查、静态构建和 Playwright 冒烟测试。
- 检查通过后以“橙子”的仓库身份提交并推送，由 Cloudflare Pages 从 `main` 自动部署。
- 推送后检查公开文章、RSS 与 sitemap 可访问；若验证或部署失败，保留线上旧版本并修复，不绕过检查。

## 隐私与版权

- 不包含 Stone、私人录音或对话内容。
- 不复制新闻报道正文，不引用第三方图片。
- 仅链接可追溯的公开来源。
